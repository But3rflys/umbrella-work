Lua-оверлей и приложение MusicUI.exe: приложение берет данные у Spotify и системного плеера, оверлей рисует их в игре.

- текст песни с прокруткой
- управление воспроизведением из оверлея
- Spotify и системный плеер Windows

# MusicUI (English)

## What it does

A Lua overlay plus MusicUI.exe: the app reads Spotify and the Windows player, the overlay draws it in game.

- track, cover art and progress in game
- equalizer driven by the real audio
- lyrics scrolling with the song
- playback controls from the overlay
- Spotify and the Windows system player

## Install

1. Download `MusicUI.zip` from the latest release and unzip it.
2. Put `MusicUI.lua` into the `scripts` folder next to your cheat.
3. Run `MusicUI.exe` and follow the prompts in the console.

The menu follows your cheat language; the script speaks Russian and English.
