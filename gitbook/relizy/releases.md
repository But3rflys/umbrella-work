# Как устроены релизы

Все скрипты и MusicUI лежат в одном репозитории [umbrella-work](https://github.com/But3rflys/umbrella-work). Релизы помечаются тегом вида `<скрипт>-v<версия>`, например `lane-pull-v1.0.3`.

## Обновление

Скачай файл из свежего релиза и замени им старый в папке `scripts`. Настройки не сбрасываются: они хранятся отдельно от файла скрипта.

## Загрузки

GitHub считает загрузки только у файлов, приложенных к релизу. Сводка по всем скриптам лежит в [README репозитория](https://github.com/But3rflys/umbrella-work#downloads) и обновляется раз в сутки.
