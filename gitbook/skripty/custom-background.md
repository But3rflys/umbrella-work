## Как работает

Каждая картинка настраивается отдельно: источник, размер, прозрачность, положение. Пока картинка не закреплена, ее можно таскать мышью. По умолчанию картинки видны только при открытом меню чита, но режим переключается.

{% hint style="info" %}
Источник — прямая ссылка на картинку или имя файла рядом со скриптами. Применяется само, сохранять ничего не нужно.
{% endhint %}

## Установка

1. Скачай `custom_background.lua` из последнего релиза.
2. Положи файл в папку `scripts` рядом с читом.
3. Открой **Scripts → Кастом фон** и включи скрипт.
