## How it works

Every picture is set up on its own: source, size, opacity, position. While a picture is not locked, you can drag it with the mouse. By default the pictures show only while the cheat menu is open, but that can be switched off.

{% hint style="info" %}
The source is a direct link to an image or the name of a file next to your scripts. It applies on its own, nothing to save.
{% endhint %}

## Install

1. Download `custom_background.lua` from the latest release.
2. Put the file into the `scripts` folder next to your cheat.
3. Open **Scripts → Кастом фон** and turn it on.
