## How it works

The script shows the nearby camps and everything the block needs: the Vacuum radius, the cast point and the exact spot to stand on. One key walks the hero to the right distance and casts once the creep condition is met. It only works while the camp creeps are visible.

## Install

1. Download `ds_spot_block.lua` from the latest release.
2. Put the file into the `scripts` folder next to your cheat.
3. Open **Heroes → Dark Seer → Spot Block** and turn it on.
