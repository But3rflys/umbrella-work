# How releases work

Every script and MusicUI live in one repository, [umbrella-work](https://github.com/But3rflys/umbrella-work). Releases are tagged `<script>-v<version>`, for example `lane-pull-v1.0.3`.

## Updating

Download the file from a fresh release and replace the old one in your `scripts` folder. Settings are not reset: they live apart from the script file.

## Downloads

GitHub counts downloads only for files attached to a release. The per-script summary lives in the [repository README](https://github.com/But3rflys/umbrella-work#downloads) and is refreshed once a day.
