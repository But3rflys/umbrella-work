# umbrella-work

Scripts for Umbrella and the MusicUI app. Each one has its own page: what it does and where to grab any version.

{% hint style="info" %}
The menu follows your cheat language — the scripts speak English and Russian.
{% endhint %}

## Install

1. Open the page of the script you need and download the file from its latest release.
2. Put the `.lua` into the `scripts` folder next to your cheat. Unzip MusicUI first.
3. Open **Scripts** in the cheat menu and turn it on.
