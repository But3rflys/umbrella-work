УстановкаInstall

  1. Открой страницу нужного скрипта и скачай файл из последнего релиза.
  2. Положи .lua в папку scripts рядом с читом. MusicUI сначала распакуй.
  3. Открой Scripts в меню чита и включи скрипт.

Язык меню берется из языка чита: скрипты говорят по-русски и по-английски.

  1. Open the script page and download the file from its latest release.
  2. Put the .lua into the scripts folder next to your cheat. Unzip MusicUI first.
  3. Open Scripts in the cheat menu and turn it on.

The menu follows your cheat language: the scripts speak Russian and English.
