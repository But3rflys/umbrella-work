# CustomEntities
Table to work with specific abilities.

CustomEntities.GetSpiritBear(spiritBear: CAbility) -> CNPC|nil
  Accept the Spirit Bear ability and return linked Bear.
  spiritBear: The Spirit Bear ability.
CustomEntities.GetVengeIllusion(commandAura: CAbility) -> CNPC|nil
  Accept the Vengeful Spirit's Command Aura ability and return scepter linked illusion.
  commandAura: The Command Aura ability.
CustomEntities.GetTetheredUnit(tether: CAbility) -> CNPC|nil
  Accept the Wisp's Tether ability and return linked unit.
  tether: The Tether ability.
CustomEntities.GetTempestDouble(tempestDouble: CAbility) -> CNPC|nil
  Accept the Arc Warden's Tempest Double ability and return linked clone.
  tempestDouble: The Tempest Double ability.
CustomEntities.GetMeepoIndex(dividedWeStand: CAbility) -> integer|nil
  Accept the Meepo's Divided We Stand ability and return index of Meepo.
  dividedWeStand: The Divided We Stand ability.
