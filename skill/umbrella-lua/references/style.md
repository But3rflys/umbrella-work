# Стиль текста, отрисовки и кода

## Текст меню

- Без длинных тире, декоративных кавычек, эмодзи и прочей нарочитой типографики. Предложения простые, через запятую и точку.
- Название пункта в 1-4 слова. Подсказка в одну-две строки, до ~50 символов в строке, перенос через `\n`.
- Игровые слова берем такие, как говорят в русском комьюнити: крип, волна, пачка, саммоны, вышка, т1/т2, хг, линия, мид. Предмет называем «Доминатор», взятого им крипа «крип с Доминатора». Своих терминов не придумываем.
- Английский текст пишется простым живым языком и совпадает с русским по смыслу.

## Отрисовка

Главное правило: минимализм. Пользователи не принимают перегруженный «сгенерированный» вид. Без всплывающих подсказок, буквенных бейджей, цветных обводок, пульсации, декоративных линий и лишних групп настроек. Самодельные значки из фигур тоже не нужны, вместо них берем настоящие иконки из игры (`Render.LoadImage("panorama/images/...png.vtex_c")`).

Проверенные варианты:

- Строка статуса высотой 26 px: темный полупрозрачный фон со скруглением. Слева иконка 20 px (скругленный квадрат, картинка обрезана до квадрата через uv без искажения, тонкая светлая обводка с альфой ~30). Дальше короткий жирный текст Segoe UI 12 px, разделитель 1×14 px, серый контекст 11 px и главная цифра цветом состояния: таймер `0:12`, расстояние, «5 крипов». Без цветных точек и подкраски фона.
- Карточка способности около 22 px: настоящая иконка, сверху полоска состояния (красная или зеленая, с легким свечением), внизу иконки мягкое затемнение. Углы скруглены, обводок нет.

Техника:

- Шрифт: `Render.LoadFont("Segoe UI", Enum.FontCreate.FONTFLAG_ANTIALIAS, Enum.FontWeight.SEMIBOLD)`.
- Плавность: `x = x + (target - x) * (1 - math.exp(-dt * speed))`, где `dt = math.min(0.1, GlobalVars.GetAbsFrameTime())`.
- Появление и исчезновение делаем альфой каждого элемента. `Render.SetGlobalAlpha` не годится: с ним `Render.Blur` при затухании чернеет.
- `Render.Shadow` дает прямоугольную тень, под скругленными формами не используем.
- Текст и иконки внутри плашки обрезаем через `Render.PushClip`/`Render.PopClip`.
- В шестеренке «Оформление» держим размер (`%`), положение X (`%` ширины экрана) и отступ сверху (px). Если панель нужно настраивать из главного меню, добавь переключатель «Только в матче» и рисуй через `OnFrame`.
- Отрисовку оборачиваем в `pcall`, а ошибку пишем в лог один раз, без спама каждый кадр:

```lua
function script.OnFrame()
	if not ui.enable:Get() then return end
	local ok, err = pcall(draw_panel)
	if not ok and err ~= state.draw_error then
		state.draw_error = err
		Log.Write("[Name] draw: " .. tostring(err))
	end
end
```

Если неясно, какой вид понравится пользователю, предложи сначала показать 2-3 варианта макетом в браузере в реальном размере и только потом пиши Lua.

## Код

- Без поясняющих комментариев. Объяснения даем в ответе пользователю.
- Имена в snake_case. Константы собираем в таблицу `K` в UPPER_CASE, состояние в `state`, пункты меню в `ui`.
- Отступы такие же, как в файле. В новых файлах используем табы.
- Ради сокращения глобальных обращений в горячих местах можно завести `local Enum_X = Enum.X`, но число локальных в главном блоке меньше 200.
- В `OnUpdate` тяжелую логику ограничиваем интервалом:

```lua
local now = GameRules.GetGameTime()
if now < state.next_run then return end
state.next_run = now + K.UPDATE_INTERVAL
```
