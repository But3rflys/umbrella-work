# Локализация (qLocalizer)

Локализация есть в каждом скрипте, даже в самом маленьком. Все скрипты выходят на `en` и `ru`. Текст меню меняется сразу, как только пользователь переключает язык Umbrella, перезагрузка не нужна.

Библиотека qLocalization (автор qfun) встраивается в сам файл блоком `local qLocalization = (function() ... end)()`. В скрипт его вставляет `luatool.exe` (команды `new` и `migrate`), блок вшит в утилиту. Внутри файла это локальная переменная, поэтому с другими скриптами блок не конфликтует. Отдельный `!_qLocalizer.lua` скрипту не нужен. Блок не читай, не правь и не копируй в файл вручную.

## Подключение

Сразу под блоком библиотеки:

```lua
local localization = qLocalization.new({
	en = {
		lp_group_main = "The basics",
		lp_enable = "Turn it on",
		lp_enable_tip = "Hit the key and your creep grabs\nthe enemy wave and drags it to you",
		lp_pick = "Which wave to grab",
		lp_picks_hero = "Closest to me",
		lp_picks_cursor = "By my cursor",
		lp_st_wait = "Waiting for the %s wave",
	},
	ru = {
		lp_group_main = "Основное",
		lp_enable = "Включить",
		lp_enable_tip = "Крип с Доминатора по нажатию клавиши забирает\nвражескую волну и ведет ее к герою",
		lp_pick = "Какую волну пулить",
		lp_picks_hero = "Ближайшую к герою",
		lp_picks_cursor = "У курсора",
		lp_st_wait = "Жду волну %s",
	},
})

local UI = localization.WrapLibrary(Menu)
local L = localization.Get
```

Меню создается только через `UI`. Методы экземпляра вызываются через точку: `localization.Get(key)`. Запись `localization:Get` передаст лишний аргумент.

## Ключи

- Ключи плоские: `<префикс>_<имя>`, только строчные буквы, цифры и `_`. Префикс из 2-3 букв по имени скрипта (`lane_pull` дает `lp`).
- Ключи без точек. Ключ служит и внутренним именем пункта, по которому Umbrella сохраняет настройку в `gui.json`. Точку Umbrella читает как разделитель пути, поэтому пункт `menu.enabled` после перезахода сбрасывается. Вложенные таблицы (`menu = { enabled = ... }`) библиотека понимает, но они дают как раз такие имена, поэтому словарь только плоский.
- Каждый ключ есть во всех языках. `en` служит запасным: если строки нет в текущем языке, берется английская, а если нет и ее, на экране окажется сам ключ.
- Имена ключей строятся по схеме: `_tip` для подсказки, `_group_*` для группы, `_gear_*` для шестеренки, пункты Combo от общего корня (`lp_pick` → `lp_picks_hero`, `lp_picks_cursor`).

## Что переводит обертка сама

| Где | Как |
| --- | --- |
| Имена пунктов | ключ в `Switch`, `Bind`, `Slider`, `Button`, `Combo`, `MultiCombo`, `MultiSelect`, `Input`, `Label`, `ColorPicker` |
| Группы | `page:Create(key, Enum.GroupSide.Left)` |
| Шестеренки | `widget:Gear(key)` |
| Подсказки | `widget:ToolTip(key)` |
| Пункты Combo | список ключей в `g:Combo(key, { k1, k2 }, 0)` и в `combo:Update({ k1, k2 })` |

Не переводятся:
- имена вкладок в `UI.Create(...)` и `tab:Create(...)`. Их пишем обычным английским текстом;
- пункты `MultiSelect` и `MultiCombo`. Их `id` делай постоянными английскими строками: по ним сохраняются галочки;
- строка для `bind:Properties(...)`. Передавай `L("<p>_bind_name")`.

## Текст вне меню

Строки для отрисовки и уведомлений берем через `L(key)`, подстановки делаем через `string.format(L("lp_st_wait"), lane)`. Для русских числительных заводим три формы и выбираем нужную:

```lua
local function plural(n, one, few, many)
	local m10, m100 = n % 10, n % 100
	if m10 == 1 and m100 ~= 11 then return L(one) end
	if m10 >= 2 and m10 <= 4 and (m100 < 12 or m100 > 14) then return L(few) end
	return L(many)
end
```

В английском словаре у тех же ключей формы `"creep"`, `"creeps"`, `"creeps"`.

Отладочный лог (`Log.Write`) можно писать по-английски без перевода: его читает разработчик.

## Особенности

- Combo сохраняет выбранный пункт текстом. Если пользователь сменил язык между запусками, выбор в переведенном Combo может сброситься на значение по умолчанию. Для настроек, где это критично, лучше `Switch`.
- Обертка переводит все, что создано или найдено через нее, в том числе результат `Menu.Find` от обернутого `Menu`. Пункт, найденный глобальным `Menu.Find` до обертки, оберни сам: `localization.Wrap(пункт, true)`. Если словарь дополнен после создания меню, вызови `localization.Update()`.
- Язык берется из настройки Umbrella `Language`. Код языка это первые буквы его названия. Если для кода нет таблицы, работает `en`.
- Перевод существующего скрипта делает `luatool.exe migrate`. Ключи из вложенного словаря получают имя по пути: `menu.enabled` становится `<p>_menu_enabled`, общий для всего словаря корень отбрасывается. Уже плоские ключи не переименовываются. Текст из кода получает ключ по имени переменной (`ui.enable` дает `<p>_enable`, подсказка `<p>_enable_tip`), а без переменной по первым словам текста. Кириллица уходит в `ru`, остальное в `en`. Недостающие переводы из строк `NEED` допиши сам. Имена пунктов меняются, поэтому их сохраненные значения один раз сбросятся, предупреди об этом пользователя. С точками в именах они и так не сохранялись.
