# Стиль плашки

Проверенный стиль для любого элемента отрисовки: метки над объектом в мире, строки статуса на экране, строки списка. Слева иконка, справа короткий текст, все на темной полупрозрачной таблетке. Все числа даны для масштаба 1, в меню их умножают на ползунок «Размер» (80-160%).

## Основа

- Таблетка высотой `h = 32`, округленной до четного, `r = h / 2`. Фон `Color(14, 16, 18, 184)`, скругление `r`, флаг `Enum.DrawFlags.RoundCornersAll`.
- Под фоном размытие `Render.Blur(pa, pb, alpha, 1.0, r, RoundCornersAll)` по переключателю «Размытие фона». Сила равна альфе плашки. Если плашка сворачивается до одной иконки, размытие под иконкой оставляй, иначе видно, как оно гаснет.
- Содержимое после иконки: отступ 6, между элементами 8, хвост 12. Главное жирным 12 px цветом состояния, дальше разделитель 1×14 (белый, альфа 46) и детали обычным 11 px серым.
- Шрифт `Render.LoadFont("Inter", Enum.FontCreate.FONTFLAG_ANTIALIAS, Enum.FontWeight.BOLD)` и `NORMAL`, запасной `"Segoe UI"`.
- Цвета: хорошо `111, 214, 111`, плохо `232, 98, 90`, текст `240, 240, 242`, серый `150, 154, 160`. Смену цвета состояния анимируй по каналам.
- Таймеры и числа рисуй табличными цифрами: каждую цифру отдельно по ширине самой широкой, иначе текст дрожит при смене `0:10` на `0:09`.
- Текст обрезается по таблетке через `Render.PushClip`/`Render.PopClip`.
- Без обводок таблетки, свечения, теней и цветных точек.

## Иконка слева

Источник иконки любой, лишь бы она читалась в 24 px и была в том же стиле:

- картинка из игры: способность, предмет, герой (`Render.LoadImage("panorama/images/...png.vtex_c")`);
- глиф FontAwesome, как в меню: `Render.LoadFont("FontAwesomeEx", Enum.FontCreate.FONTFLAG_ANTIALIAS, 400)`, глиф рисуется текстом цветом текста или состояния, центрируется через `Render.TextSize`;
- элемент из примитивов, как переключатель ниже: скругленные прямоугольники, круги и дуги из `Render.FilledRect`, `Render.FilledCircle`, `Render.Circle` в цветах плашки. Например, индикатор вкл/выкл или точка состояния.

Форма под иконкой по смыслу:

- Круг. Картинка 24 px, круглая: `Render.Image(handle, pos, size, color, size / 2, RoundCornersAll, Vec2(0, 0), Vec2(1, 1), gray)`.
- Скругленный квадрат. Картинка способности или предмета 24 px со скруглением 5: `Render.Image(handle, pos, size, color, 5, RoundCornersAll, Vec2(0, 0), Vec2(1, 1), gray)`, поверх тонкая светлая обводка `Render.Rect(pos, pos + size, Color(255, 255, 255, 30), 5, RoundCornersAll, 1)`. Подходит для списков скиллов и предметов, где прогресс не нужен.
- Без подложки. Глиф или элемент из примитивов стоит прямо на таблетке, отступ слева такой же, как у круга.

У выключенного объекта картинка серая (последний аргумент `Render.Image` равен `1.0`), глиф и примитивы серым цветом `174, 178, 184`, а альфа плашки в покое ниже.

## Раскрытие

Плашка может в покое быть одной иконкой и раскрываться в таблетку при наведении или когда есть что показать. Активные и наведенные плашки рисуй вторым проходом, поверх остальных. Пока таблетка сворачивается, рисуй прошлое содержимое, а не пустоту.

Ширину меняй за фиксированное время, а не экспонентой: экспонента доползает последние пиксели по одному, и это выглядит как низкий fps. 0.15 с, ease-out cubic, новая цель стартует с текущей ширины:

```lua
local function tween_width(an, target)
	if an.w == nil then
		an.w, an.w_to, an.w_t = target, target, 1
	elseif an.w_to ~= target then
		an.w_from, an.w_to, an.w_t = an.w, target, 0
	end
	if an.w_t < 1 then
		an.w_t = math.min(1, an.w_t + an.dt / K.WIDTH_TIME)
		local k = 1 - an.w_t
		an.w = an.w_from + (an.w_to - an.w_from) * (1 - k * k * k)
	else
		an.w = an.w_to
	end
end
```

- Во время анимации ширина дробная, без округления, иначе края шагают по пикселю. Конечная ширина целая и четная.
- Над точкой в мире таблетка раскрывается во все стороны от центра, так она занимает меньше места. В строке на экране раскрывается от иконки в сторону свободного места.
- Опорную точку округляй один раз, фон, иконку и текст рисуй от одних и тех же координат. Тогда при движении камеры текст не дрожит относительно фона.
- Альфа, появление текста и цвет догоняют цель экспонентой `1 - math.exp(-dt * speed)` со скоростями около 20-30. `dt = math.min(0.1, GlobalVars.GetAbsFrameTime())`.
- Затухание делай альфой каждого элемента, не `Render.SetGlobalAlpha`.

## Наведение с запасом

Если плашка при наведении меняет ширину, а зона наведения равна текущей ширине, у края она начинает дергаться: сузилась, курсор снаружи, расширилась, курсор внутри. Пока курсор наведен, держи зону не уже ширины на момент наведения плюс запас 6 px:

```lua
local w = an.w or r * 2
local pad = an.hover and 6 or 0
local zone = an.hover and math.max(w, an.hover_w or 0) + pad * 2 or w
local hovered = Input.IsCursorInRect(p.x - zone / 2, p.y - r - pad, zone, r * 2 + pad * 2)
if hovered and not an.hover then an.hover_w = w end
an.hover = hovered
```

## Переключатель внутри плашки

Когда плашкой что-то включают и выключают, при наведении в ней стоит имя, разделитель и переключатель.

```lua
local tw, th = 24 * scale, 14 * scale
local bg = on and Color(111, 214, 111, a(153)) or Color(255, 255, 255, a(41))
Render.FilledRect(Vec2(x, cy - th / 2), Vec2(x + tw, cy + th / 2), bg, th / 2, Enum.DrawFlags.RoundCornersAll)
local kx = on and (x + tw - th / 2) or (x + th / 2)
Render.FilledCircle(Vec2(kx, cy), th / 2 - 2 * scale, on and Color(255, 255, 255, a(255)) or Color(174, 178, 184, a(255)))
```

Клик ловится в `OnKeyEvent`, и нажатие, и отпускание глотаются, чтобы клик не ушел в игру:

```lua
function script.OnKeyEvent(data)
	if data.key ~= Enum.ButtonCode.KEY_MOUSE1 then return true end
	if data.event == Enum.EKeyEvent.EKeyEvent_KEY_DOWN then
		if state.hover and not Input.IsInputCaptured() then
			toggle(state.hover)
			state.swallow = true
			return false
		end
	elseif data.event == Enum.EKeyEvent.EKeyEvent_KEY_UP and state.swallow then
		state.swallow = false
		return false
	end
	return true
end
```

## Меню оформления

У переключателя плашек шестеренка: «Размер» (`%d%%`, f065), «В покое» (альфа плашек без статуса, f043), «Размытие фона» (f042) и переключатели для необязательных подписей (f036). Все они гаснут через `:Disabled`, когда плашки выключены.
